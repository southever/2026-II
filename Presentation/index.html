小组5

家庭光伏-储能-EV 系统最终工程评估

主线：时间错配 → 数据建模 → EV 行为 → 储能选型 → 策略优化 → 条件化推荐

阮梦婷 · 谢上涛 · 陶正 · 赖康 · 刘逸文

各位老师好，我们组汇报的题目是家庭光伏、储能和电动汽车系统的全年仿真与工程评估。今天我会按一条工程主线来讲：先说明时间错配问题，再讲负荷、光伏和 EV 怎么建模，接着讲储能选型和运行策略，最后加入工业园区适配拓展，并给出条件化推荐。

CORE QUESTION

家庭光储 EV 系统的核心矛盾是时间错配

系统问题 / 汇报主线
不是电量不够，而是时间对不上白天光伏富余，晚上负荷和 EV 充电集中；储能和策略的价值，就是把这两个时段连接起来。
01 / 供给
白天光伏集中出力中午可能出现富余，上网或被本地消纳。
02 / 需求
晚上负荷与 EV 叠加家庭晚高峰和充电行为决定购电峰值。
03 / 调度
储能搬移能量在效率、SOC、功率和成本约束下优化运行。
本项目不是证明“全年电量够不够”，而是评估“什么时候有电、什么时候需要电”。

这一页先定调。家庭光伏系统最麻烦的不是全年发电量和用电量简单相加，而是时间错配：白天光伏多，晚上负荷和 EV 充电多。储能和 EV 策略的价值，都是围绕这个时间错配展开的。

这一页看负荷变化。家庭负荷主要是早晚生活高峰，工厂负荷更接近生产节奏，白天有明显平台，夜间也可能保留基荷。负荷规模和功率波动变大以后，储能不只是做光伏消纳，也更明显地承担削峰作用。

SYNTHESIS

项目要求的四个核心问题可以集中回答

综合结论 / 四问回答

EV 加入有什么影响？

影响峰值的关键是充电时段，S2 谷时延迟晚高峰最低。

容量越大越好吗？

不一定，投资成本、上网电价和损耗会抵消收益。

功率越大越好吗？

不一定，过小受限，过大可能增加投资和瞬时购电峰值。

经济性受谁影响最大？

光伏出力、上网电价、电池成本、峰谷价差和 EV 策略共同决定。

最终结论

这一页面向任务七。老师最可能问四件事：EV 对峰值的影响、储能容量是否越大越好、功率是否越大越好、哪个因素最影响经济性。我们用前面的结果把这四个问题集中回答。

RECOMMENDATION

面向不同目标，系统方案应采用条件化推荐

A / 综合结论 / 最终推荐
投资优先
小容量或暂不配置储能在当前成本口径下，可降低初始投资与回收不确定性。
电费优先
EV 谷时延迟 + 分时调度利用峰谷价差降低购电成本，但需关注循环次数增加。
寿命优先
光伏优先消纳策略减少不必要谷时补电，使储能运行更平稳。
协同优先
EV 光伏富余优先提高白天光伏消纳能力，缓解光伏与负荷的时间错配。
扩展优先
预测辅助调度为后续接入天气预测、电价预测和出行预测提供接口。
最终推荐不是单一容量或单一策略，而是根据投资、电费、寿命和协同目标进行选择。

最后给出推荐时，我们不把结论写成某个容量绝对最优，而是按照不同目标分类。投资优先时，小容量或暂不配置储能更稳；电费优先时，可以考虑谷时延迟和分时调度；寿命优先时，光伏优先策略更平稳；如果强调创新和扩展，则可以引入预测辅助调度。
