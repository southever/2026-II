# 课堂汇报 HTML PPT

## 打开方式

直接用浏览器打开：

```text
Presentation/index.html
```

建议使用 Chrome 或 Edge，并切到全屏展示。

最终课堂汇报稿可单独打开：

```text
Presentation/final_speech.html
```

## 快捷键

| 按键 | 功能 |
|---|---|
| 右方向键 / Space / PageDown | 下一页 |
| 左方向键 / PageUp | 上一页 |
| Home | 首页 |
| End | 末页 |
| F | 全屏 |
| S | 打开演讲者窗口 |

## 内容结构

- 1-26 页全部为课堂汇报主线。
- 所有关键图表都已放入主线页面，不再单独设置备用页。
- 每一页都包含隐藏演讲备注，按 `S` 可以查看。

## 设计风格

按照 `D:\design.md\HP.md` 的 HP 风格制作：

- 白底
- HP Electric Blue 强调色
- 大字号、粗标题
- 16px 软圆角卡片
- 蓝色斜切装饰
- 企业产品发布式汇报风格

## 注意

PPT 中图片均使用相对路径引用仓库内原始图表，因此不要单独移动 `Presentation` 文件夹。若需要分享，请连同整个 `2026-II` 仓库一起分享。
